# Version 1
Die Version 1 hat 3 Dateien, welche ausgeführt werden müssen, um das Programm zu starten.

## Benötigte Bibliotheken
Diese Version verwendet die gleichen Bibliotheken wie die Version 2.

### susImport.py
Diese Datei beinhaltet die Schüler Importfunktion. Bei jeder Ausführung kann diese eine Klasse importieren. Dies ist in der BLL dokumentiert.

### projekteImport.py
Diese Datei beinhaltet den Projekteimport. Diese Datei erstellt auch das Platzhalterprojekt. 

### main.py 
Dieses Projekt startet den Algorithmus und speichert die Ergebnisse. 

### Neues Projekt erstellen
Um ein neues Projekt anzufangen, muss man die schueler.json und projekte.json löschen.
